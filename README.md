# Oklahoma Physical Therapy — redesign

This repo contains a **patient-conversion redesign** of [oklahomaphysicaltherapy.com](https://oklahomaphysicaltherapy.com/).

The working Next.js app lives in [`site/`](./site/).

## Highlights

- Online booking flow by clinic, reason, clinician, and time
- Insurance + cash-pay surfaced above the fold
- Condition pages for pelvic floor, spine, and sports/golf
- Location pages with hours, maps, and staff

```bash
cd site && npm install && npm run dev
```

Original sprint-review notes remain in `Sprint Review.docx`.
